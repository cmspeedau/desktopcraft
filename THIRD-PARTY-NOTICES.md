## Local Modified Libraries

### `macroquad` 0.4.16 (local adaptation in `vendor/macroquad`)
- **License:** `MIT OR Apache-2.0`
- **Repository:** https://github.com/not-fl3/macroquad
- **Original Copyright Notice:** Copyright (c) 2019-2021 Fedor Logachev <not.fl3@gmail.com>
- **Local Modifications:** Accumulates high-resolution Windows mouse wheel deltas across frames and reports keyboard auto-repeat events, and includes a local texture-atlas correction in text/atlas.rs. The unused random module and quad-rand re-exports were removed from the local adaptation; upstream example targets/assets were omitted. Original `LICENSE-MIT` and `LICENSE-APACHE` files are preserved in `vendor/macroquad/`.

### `miniquad` 0.4.11 (local adaptation in `vendor/miniquad`)
- **License:** `MIT OR Apache-2.0`

- **Original Copyright Notice:** Copyright (c) 2019-2020 Fedor Logachev <not.fl3@gmail.com>

## System Fonts & Embedded Application Icon Assets

- **Windows System Fonts:** DesktopCraft loads standard Windows system fonts (`LeelawUI.ttf`, `tahoma.ttf`, `segoeui.ttf`) from `C:\Windows\Fonts` at runtime and invokes Windows GDI `SPI_GETICONTITLELOGFONT` for native label rendering. No Microsoft font files are bundled in the production distribution. Macroquad embeds ProggyClean.ttf, copyright (c) 2004, 2005 Tristan Grimmer, under MIT; see third-party-licenses/ProggyClean/LICENSE-MIT. Font SHA-256 matches Dear ImGui v1.91.9 misc/fonts/ProggyClean.ttf: 527d2a443ce051f93f7e77b855609722b8cb220a9f104b4aa037be5c90b71324 (upstream https://github.com/ocornut/imgui/tree/v1.91.9/misc/fonts).
- **Application Icon (`assets/desktopcraft.ico` and `assets/desktopcraft-*.rgba`):** Derived from artwork supplied by the DesktopCraft product owner, who confirmed on 2026-11-24 that it was generated using ChatGPT. See assets/README.md for conversion lineage, applicable output terms and remaining third-party rights limitations. The code license does not automatically establish an artwork license.
